# Engineering

Streamline engineering workflows — standups, code review, architecture
decisions, incident response, and technical documentation. Works with your
existing tools or standalone.

## What it does

- Drafts and summarizes standups, PR descriptions, and release notes.
- Reviews code for correctness, readability, and common pitfalls.
- Helps reason through architecture and design trade-offs.
- Guides incident response and writes postmortems.
- Produces technical docs, runbooks, and onboarding guides.

## Use cases

- Faster, more consistent code review feedback.
- Design docs and RFCs from a rough idea.
- Incident timelines and blameless postmortems.
- Keeping documentation in sync with the codebase.

## Example prompts

- "Review this diff and flag edge cases or missing tests."
- "Draft an RFC for moving auth to Supabase."
- "Write a runbook for rotating the service role key."

## Inputs & outputs

- **Inputs:** diffs, stack traces, logs, requirements, existing docs.
- **Outputs:** review comments, design docs, runbooks, summaries.
