# Data

Write SQL, explore datasets, and generate insights faster. Build
visualizations and dashboards, and turn raw data into clear stories for
stakeholders.

## What it does

- Authors and optimizes SQL across common warehouses and databases.
- Explores datasets: profiling, joins, aggregations, and sanity checks.
- Generates charts, dashboards, and summary metrics from query results.
- Explains findings in plain language for non-technical stakeholders.

## Use cases

- Ad-hoc analysis: "How did signups trend by week last quarter?"
- Metric definitions and reusable query snippets.
- Dashboard scaffolding and KPI reporting.
- Data quality checks and anomaly spotting.

## Example prompts

- "Write a query for weekly active users, grouped by plan."
- "Summarize this CSV and flag any outliers."
- "Turn these results into a short update for the leadership channel."

## Inputs & outputs

- **Inputs:** table schemas, sample rows, CSV/JSON exports, a question.
- **Outputs:** SQL, tables, charts, and a written summary.
